Privacy Policy

Enzo Web Console is a desktop tool used only by its owner on their own computer. This policy explains what Google user data it accesses and what it does with it.

Data the tool accesses

With the owner's consent through Google's sign-in screen, the tool requests these permissions:

  • Read-only: Google Tag Manager (view containers) and Google Analytics (view properties and data streams), plus the account's email address to show which account is connected.
  • Deployment (requested separately, only when needed): Google Tag Manager (edit containers, create versions, publish) and Google Analytics (edit property settings such as key events).

How the data is used

The data is used only to show the owner how tracking is configured on their own websites and to apply changes the owner has approved. It is not used for advertising, profiling, or any other purpose.

Storage

Sign-in tokens are stored in the macOS Keychain on the owner's computer. Short-lived access tokens are kept in memory only. Container and property details read from Google are processed on the owner's computer and are not uploaded to any server operated by the tool.

Sharing

Google user data is not sold, transferred, or shared with any third party. No one other than the owner has access to it.

Limited Use

Enzo Web Console's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can disconnect a Google account from inside the tool, which revokes its tokens and deletes them from the Keychain. Access can also be removed at any time at myaccount.google.com/permissions.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
