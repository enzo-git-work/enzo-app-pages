Enzo Web Console

A private desktop tool that helps its owner manage analytics and tag configuration for the websites they run.

What it does

Enzo Web Console runs only on its owner's own computer. When the owner connects a Google account, the tool can:

  • read Google Tag Manager containers and Google Analytics 4 properties the owner already has access to, to check that tracking is set up correctly;
  • after the owner reviews and approves a change, write that change into a new Google Tag Manager workspace, publish it, and roll it back if needed.

Every change to a live container requires the owner's explicit approval inside the tool. The tool is not offered to the public and has no user accounts or sign-up.
